TITLE:
WorkProof — Freelance work. Verified by consensus.

DESCRIPTION (993 chars):
WorkProof is a trustless work verification and settlement protocol on GenLayer. Clients create work contracts with objective acceptance criteria and lock GEN escrow; freelancers submit evidence URLs; validators retrieve the evidence from the live web and score every criterion PASS / FAIL / UNVERIFIABLE, settling only when they agree on per-criterion results. A review window protects both sides: clients release or dispute a passing verdict, freelancers force-release after 3 days, and disputes re-arbitrate under the original immutable criteria. The React frontend ships real wallet connection (EIP-6963), a criteria builder with an on-chain AI drafting assistant, per-criterion result tables, on-chain deadlines, a capped protocol fee, mutual amendments, ratings with on-chain reputation, a built-in testnet faucet, and a labeled demo mode. 34 contract tests + 33 frontend tests. Verified live on StudioNet: validators fetched example.com and scored criteria with evidence-based reasoning.
