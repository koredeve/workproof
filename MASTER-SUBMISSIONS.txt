TITLE:
WorkProof — Freelance work. Verified by consensus.

DESCRIPTION (max 1000 chars):
WorkProof is a trustless work verification and escrow protocol on GenLayer. Clients create contracts with objective acceptance criteria and fund escrow; freelancers submit evidence URLs; validators retrieve evidence from the live web and score every criterion (PASS/FAIL/UNVERIFIABLE), reaching consensus on complete per-criterion maps with zero mismatch tolerance before funds move. Review & dispute windows protect both parties: clients approve or dispute passing work, freelancers force-release after 3 days, and disputes re-arbitrate strictly under original immutable criteria. The React frontend features EIP-6963 multi-wallet connection, an on-chain AI drafting assistant, mutual amendments, on-chain deadlines, capped protocol fees, reputation ratings, a built-in testnet faucet, and a labeled demo mode. 44 contract tests (including complete-consensus adversarial suites) + 36 frontend tests. Live on StudioNet with verified evidence-based rulings.
